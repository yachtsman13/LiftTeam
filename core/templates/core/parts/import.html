Требования к файлу

Файл должен быть в формате .xlsx и содержать следующие колонки:

  • part_number — артикул (обязательно)
  • name — название (обязательно)
  • component_type — тип компонента (обязательно)
  • package — тип корпуса: 0805, DIP-8, TO-220
  • price — закупочная цена за штуку

Опциональные колонки:

  • voltage, current, power, resistance, capacitance
  • min_stock — мин. остаток (по умолчанию 5)
  • current_stock — текущий остаток (по умолчанию 0)
  • lead_time_days — срок поставки (по умолчанию 14)
  • description — описание
