{% comment %} Выбор детали из каталога — один на всю программу. Заменяет собой обычный список деталей: в каталоге сотни записей, и листать их, чтобы найти одну, невозможно. Наружу отдаёт то же самое, что отдавал список: скрытое поле с номером детали под прежним именем. Поэтому принимающие представления и формы менять не нужно. Подключение (одной строкой вместо поля формы): {% include 'core/_part_picker.html' with name=form.part.html_name %} Параметры: name — имя поля, под которым уйдёт номер детали (обязательный); value — выбранная деталь (номер), если выбор уже сделан; value_label — как её подписать; если не передать, подпись запросится у сервера по номеру; placeholder — что писать, пока ничего не выбрано; exclude — номера деталей через запятую, которые здесь выбирать нельзя; default_no_cell — пока поле поиска пустое, показывать только детали без назначенной ячейки (для выбора «куда положить» — добавление детали в ячейку кассетницы). Начали печатать — ограничение снимается, ищем по всему каталогу. Разметка намеренно обходится без Bootstrap JS: ни `data-bs-toggle`, ни `modal`. Bootstrap приезжает из интернета, и если он не приехал — а на телефоне через Tailscale это обычное дело — выбор детали обязан работать всё равно. Прячется панель атрибутом `hidden`, за которым в base.html закреплено `display: none !important`. {% endcomment %}
